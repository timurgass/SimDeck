# Farming Simulator 25: состояние интеграции

В SimDeck 0.8.9 профиль FS25 содержит 53 действия на пяти страницах. Клавиша Q теперь представлена одной кнопкой **«Прицепить / отцепить»**; отдельная Ctrl+Q убрана из стандартного набора. Если она нужна для особого случая, её можно добавить как пользовательскую кнопку. Companion читает `inputBinding.xml` только для импорта назначений и не меняет файл игры. Пользовательские кнопки SimDeck и их клавиши сохраняются при обновлении.

Companion также читает четыре XML-файла последнего сохранения (`careerSavegame.xml`, `environment.xml`, `farms.xml`, `fields.xml`) и передаёт на Android и в Safari название сохранения, карту, период, деньги, кредит и состояние полей. Советник строит предупреждения о сорняках, извести, готовности к уборке и финансах. Кнопка **«Загрузить план FS25»** в Companion принимает JSON-план версии 1 и показывает задачи с вычисленным состоянием. [Формат плана](FS25-SEASON-PLAN.md).

Это **данные последнего сохранения**, а не непрерывная телеметрия машины: изменения в игре появятся после сохранения. Экран показывает время записи и пометку устаревания. Игра должна быть запущена, чтобы данные считались актуальными. При частичной записи XML чтение повторяется. Справочник культур берётся из установленной игры, если её файлы доступны; без него правило окна посева не применяется. Реальные пользовательские сейвы и файлы GIANTS в репозиторий не входят.

Дополнительный [мод состояния орудий](../mods/FS25_SimDeckStatus/README.md) передаёт положение **выбранного** орудия, работу агрегата/молотилки и двигателя. Установите ZIP в игровую папку `mods`, включите мод при загрузке сохранения и перезапустите FS25. Companion читает только локальный `simdeckStatus.xml`, созданный модом; он не меняет сейв. Android и Safari подсвечивают лишь те состояния, которые мод смог определить; при отсутствии мода или устаревшем файле статус скрыт. Векторные значки действий работают и без мода. Интеграция мода пока требует ручной проверки на каждой версии игры и модифицированной технике.

Самостоятельный [макет фермерских экранов](fs25-mockup.html) остаётся примером будущего интерфейса. Действующий экран пока охватывает только сведения сохранения, предупреждения, задачи и существующие кнопки; скорость, топливо, техника, цены станций, склад и площади полей ещё не подключены.

Ручная проверка на установленной FS25: [FS25-TESTING.md](FS25-TESTING.md). Для новой игры или внешней разработки: [DEVELOPING-GAMES.md](DEVELOPING-GAMES.md).
