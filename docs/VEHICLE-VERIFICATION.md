# Проверка автоматического выбора · 0.9.3

Дата: 2 октября 2026. [Функциональность и ограничения](AUTO-VEHICLE.md).

- Companion: **293 проверки прошли**, включая чтение SMD3, 3-осный тягач, реальную раскладку SDK ETS2, отсоединение прицепа, FS25-иерархию, выход из машины, устаревание и встроенный браузерный ресурс.
- LuaJIT: выполнены исходники FS25 и BeamNG с тестовыми игровыми API. Подтверждены вложенная цепочка с защитой от циклов, смена трактора на комбайн, очистка при выходе, размер FFI-пакета 448 байт и смена модели без старого кэша.
- Android: **52 теста прошли**, APK 0.9.3 собран и установлен на подключённый планшет с сохранением данных. Установка APK сама по себе не подтверждает поведение игры.
- Chromium и WebKit: все восемь профилей на размерах 320×640, 390×844, 844×390, 800×1340, 1340×800. Проверены смена шестиколёсной машины на неизвестную, удаление предыдущей геометрии, прозрачный прицеп и выход из техники; также сохранение пользовательских действий и удержаний, блокировка ввода и отсутствие горизонтального переполнения.
- Самодостаточная Windows-сборка: нормальный запуск/закрытие и обработка занятого порта прошли.

Дополнительно подтверждён реальный FS25: опубликованный парсер Companion прочитал MT635 (tractor), четыре колеса, две оси, орудие 980 (implement), lowered=false, fold=1, мотор=true. На Android через настоящее сохранённое WSS-сопряжение появились профиль FS25, MT635 и «Поднято». Пульт переподключён кнопкой сохранённого ПК без нового PIN. При прекращении свежих данных схема очищается.

Показания в Chromium/WebKit — фикстуры. Смена нескольких классов техники и переходы положения орудия в живой игре ещё не проверены; новые поля BeamNG/ETS2 также требуют отдельного живого заезда. Windows Computer Use был остановлен Esc, поэтому управление игровым окном после этого не выполнялось. WebKit на Windows не заменяет физический iPhone. Автоматический выбор SnowRunner не реализован без живого источника данных.

Воспроизведение: [tools/qa](../tools/qa/README.md). Личные настройки, IP, сертификаты и папки сопряжения в репозиторий/архивы не включены.
