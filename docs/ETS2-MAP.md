# Карта дорог ETS2

В Companion и Android **0.9.12** карта показывает дороги, соединения перекрёстков, названия городов и положение вашего грузовика. Safari получает тот же экран из обновлённого Companion. Кнопки `＋/−` меняют масштаб; север находится сверху. Кнопка игрового действия «Карта» по-прежнему открывает навигатор в самой ETS2.

## Что установить

1. Распакуйте целиком [Windows Companion 0.9.12](https://github.com/timurgass/SimDeck/releases/download/v0.9.12/SimDeck-0.9.12-Windows.zip), затем откройте `SimDeck.exe`.
2. На Android установите [APK 0.9.12](https://github.com/timurgass/SimDeck/releases/download/v0.9.12/SimDeck-0.9.12-Android.apk) поверх предыдущей версии. Для Safari достаточно обновить страницу.
3. Если приборы ETS2 ещё не работают, установите [SCS Telemetry plugin](https://github.com/timurgass/SimDeck/releases/download/v0.8.7/SimDeck-ETS2-Telemetry-0.8.5.zip) при закрытой игре. Если телеметрия уже приходит, менять DLL не нужно.
4. Запустите ETS2, выберите профиль **ETS2** в Companion и загрузите грузовик. Карта готовится автоматически из файлов установленной игры. Дополнительный игровой мод, карта из интернета и ручное копирование файлов не нужны.
5. Откройте **Обзор** на пульте. Для текущих координат игра должна быть вне паузы. На ПК состояние подготовки видно в карточке телеметрии.

Доступ к карте защищён тем же сопряжением, что пульт. Геометрия передаётся отдельно от потока показаний: загружается область вокруг грузовика, повторная загрузка происходит при выходе из неё или раз в минуту. По Wi-Fi и USB используется одна карта.

## Ограничения

- Это **карта дорог с движущимся грузовиком**, а не копия пикселей игрового GPS. Линия выбранного маршрута, ближайшие повороты, дорожный трафик и другие игроки пока не передаются.
- Остаток пути, время и лимит скорости читаются из обычной телеметрии независимо от геометрии.
- Импорт разрешён для версий ETS2 1.59–1.61; чтение файлов и координат проверено на 1.61.1.1. Другая версия требует проверки совместимости.
- Поддерживается обычная карта и установленные файлы карт DLC. Изменения карты сторонними модами в этой версии не учитываются. При несовместимости показывается сообщение, а кнопки продолжают работать.
- Кэш хранится только на этом ПК: `%LOCALAPPDATA%/SimDeck/ets2-map`. После изменения файлов игры создаётся новый кэш. Он не входит в GitHub и общие архивы SimDeck.

Импорт использует адаптированный [ts-map](https://github.com/dariowouters/ts-map); исходники и лицензии находятся в `third_party/ts-map`. Координаты и ориентация читаются из восьмой зоны SCS SDK revision 12: X — байт 2200, Z — 2216, heading — 2224. Геометрия содержит координаты игры без привязки к реальным географическим широте и долготе.
