# Карта и навигатор ETS2 / ATS

С версии **0.9.17** используется новый общий навигатор Android Tablet, SimDeck Phone и Safari.

- С 0.9.18: леса, вода и покрытия из локальных игровых поверхностей; отдельная подложка с кэшированием.
- Дороги, города, реальные заправки, стоянки, сервисы и другие объекты из локальных файлов игры.
- Поиск, свой маршрут по дорожной сети, промежуточные остановки и ведение с перестроением.
- Слои карты, день/ночь, направление движения, следование и голосовые подсказки.
- Показания и последняя карта сохраняются при паузе или задержке; кнопки игры от телеметрии не зависят.

**[Пошаговая установка, управление и ограничения](TRUCK-NAVIGATOR.md).** С 0.9.20 режим «GPS игры» читает последовательность выбранных игрой узлов. «Свой путь» рассчитывает отдельный маршрут SimDeck. Живая проверка GPS выполнена в ATS 1.61; для ETS2 проверены сигнатуры, заезд ещё требуется. Дополнительный мод карты не требуется. Для координат нужен существующий SCS Telemetry plugin; геометрия импортируется из своей установленной ETS2/ATS.
