# SimDeck Companion 0.9.11

Windows Companion использует согласованный графитовый интерфейс с бирюзовыми акцентами. Слева — навигация; на главной странице — подключение, телеметрия, разрешение ввода и редактор кнопок. Иконка EXE и окна повторяет значок Android.

Обновляется только приложение на ПК. Android **0.9.10** и мод FS25 **1.4.0.0** совместимы и остаются прежними; переустанавливать их не требуется.

## Установка

1. Закройте Companion и полностью распакуйте `SimDeck-0.9.11-Windows.zip` в папку приложения.
2. Запустите `SimDeck.exe`. Настройки и сопряжения сохраняются в пользовательской папке SimDeck, отдельно от файлов программы.
3. Проверьте выбранный профиль и включите «Разрешить ввод» на странице «Обзор» для управления игрой.

При создании ярлыка Windows использует встроенную иконку EXE. Старому ярлыку можно назначить новую иконку через его свойства.

## Страницы

| Страница | Содержимое |
| --- | --- |
| Обзор | Подключение, скорость/RPM/передача, состояние ввода, последняя команда и кнопки |
| Устройства | Wi-Fi/USB, сопряжение Android, Safari, раскрываемые адрес и отпечаток, отзыв доступа |
| Профили | Все действия, поиск, редактор клавиш, добавление/удаление/перемещение, импорт FS25 и план сезона |
| Диагностика | Источник, количество пакетов, возраст последнего кадра, активный процесс и результат команды |
| Настройки | Имя процесса игры и демонстрационный режим |

Выбор игры в верхнем списке применяется кнопкой «Открыть». Перед сменой профиля сохраните изменения. Поиск скрывает неподходящие строки, сохраняя все действия профиля. Сохранение сохраняет полный список, включая строки вне результата поиска.

Краткая задержка источника не стирает последние приборные показания. Возраст кадра показывает задержку поступления данных игры; это не измерение сетевого ping. Ввод разрешается отдельно и не зависит от свежести телеметрии.

## Wi-Fi и USB

Для Wi-Fi подключите ПК и устройство к одной домашней сети; на Android выберите сохранённый ПК → **Wi-Fi**. Safari на iPhone также использует локальную сеть.

Для USB:

1. Сначала выполните обычное сопряжение Android по Wi-Fi.
2. Подключите планшет кабелем с передачей данных, включите отладку USB и подтвердите разрешение ПК на планшете.
3. В Companion нажмите **USB**. Программа создаст и проверит ADB reverse для своего порта; в архиве Windows есть необходимые инструменты ADB и их `NOTICE.txt`.
4. На Android выберите сохранённый ПК → **USB**. После переподключения кабеля повторите подготовку кнопкой USB.

Переключатель на ПК сохраняет выбранный режим и готовит канал. Сам по себе он не переключает Android: окончательный выбор выполняется на планшете. Подпись под устройством отражает фактическое подключение, а не только выбранную кнопку. Если подключено несколько Android-устройств, оставьте один планшет и повторите.

При сборке из исходников ADB ищется рядом с EXE в `platform-tools`, затем в Android SDK и PATH. [Официальные Android Platform Tools](https://developer.android.com/tools/releases/platform-tools).

## Проверка

- 436 проверок .NET, запуск готового EXE и корректное завершение при занятом сетевом порте.
- Рендер настоящих WPF-компонентов; навигация и сохранность действий после поиска для всех восьми профилей.
- Компоновка 1440 × 980 и 1024 × 720; на узком окне карточки располагаются вертикально.
- На подключённом Android подтверждён канал USB; готовый Companion показывает фактическое соединение.
