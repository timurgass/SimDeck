# SimDeck 0.9.14: поиск цен как в полях

Скачайте [Windows Companion и Android APK 0.9.14](https://github.com/timurgass/SimDeck/releases/tag/v0.9.14). Закройте Companion, распакуйте Windows ZIP и установите APK поверх предыдущей версии. Сопряжение и настройки сохраняются. В Safari обновите страницу после перезапуска Companion.

В «Ценах» строка **«Культура, товар или пункт продажи»** теперь видна прямо на вкладке, над выбором товара. Ввод сразу фильтрует показанные предложения. Можно ввести часть названия, например «пшени» или «порт». Регистр и пробелы по краям не влияют на результат. Поиск применяется вместе с выбранным товаром; чтобы искать среди всех товаров, выберите «Все».

Очистка строки возвращает список для текущего выбора товара. Если совпадений нет, показывается «По этому фильтру предложений нет». Новые данные не сбрасывают строку поиска.

Мод FS25 **1.5.0.0** остаётся прежним: его не нужно переустанавливать после 0.9.13. Для отправки клавиш свежие цены не требуются.
