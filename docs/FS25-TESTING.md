# Проверка Farming Simulator 25

## Профиль кнопок

1. В Companion выберите **Farming Simulator 25**. Если меняли клавиши в игре, нажмите **«Прочитать клавиши FS25»** и выберите `inputBinding.xml` из `Documents/My Games/FarmingSimulator2025`.
2. Проверьте обновлённые назначения в таблице. Импорт не меняет игровой файл; перед изменением профиля создаётся копия настроек Companion.
3. Подключите Android или Safari, откройте FS25, включите ввод в Companion и держите окно игры активным. На подходящем орудии проверьте включение агрегата, выбор культуры, двигатель и удержание сигнала. Недоступные текущей машине действия могут не иметь видимого эффекта.

## Данные сохранения и план

1. В игре сохраните ферму. Companion должен найти последний `savegame*` и показать время сохранения; на Android/Safari откройте профиль FS25. Сверьте название, карту, период, деньги и несколько полей с игрой.
2. Измените состояние поля и сохраните ещё раз. Экран должен обновиться после записи, без вымышленных промежуточных значений. Если игра закрыта или сохранение старое, проверьте пометку **«данные устарели»**.
3. При наличии JSON-плана версии 1 нажмите **«Загрузить план FS25»**, выберите файл и проверьте задачи. Неправильный JSON должен дать понятную ошибку, не стирая ранее загруженный план.
4. Сверьте предупреждения советника. Доступность культуры для посева требует файлов установленной FS25; без них это правило не утверждает, что посев разрешён или запрещён.

Текущее чтение сейва подтверждено синтетическими тестами; поведение на конкретной установленной версии FS25 и модифицированных картах нужно проверить вручную. Непрерывных показаний скорости, топлива, техники, склада и цен этот источник пока не даёт.

## Автоматические проверки

```powershell
dotnet run --project companion/SimDeck.Tests/SimDeck.Tests.csproj -c Release
dotnet build companion/SimDeck.App/SimDeck.App.csproj -c Release
cd android
./gradlew testDebugUnitTest assembleDebug
```

Тесты используют только синтетические сейвы. Игровые XML-файлы GIANTS можно добавить локально для дополнительных интеграционных проверок, но не публиковать.
