# Проверка Farming Simulator 25

## Доступно в SimDeck 0.8.4

- 54 кнопки на страницах «Орудие», «Посев», «Трактор», «Помощник», «Хозяйство».
- Импорт назначений из `inputBinding.xml` через кнопку **«Прочитать клавиши FS25»** в Companion.
- Управление с Android и Safari через обычное подключение SimDeck.

Скорость, топливо, поля, техника и сезонные советы **ещё не поступают из FS25**. [Макет](fs25-mockup.html) служит только для просмотра будущего интерфейса.

## Проверка в игре

1. Запустите Companion, выберите «Farming Simulator 25» и нажмите «Открыть профиль».
2. Если в игре изменяли клавиши, нажмите **«Прочитать клавиши FS25»**. Выберите `inputBinding.xml` из папки `My Games/FarmingSimulator2025` в ваших документах. При отсутствии папки откройте её через диалог выбора файла.
3. Проверьте сообщение о числе обновлённых клавиш и пару назначений в таблице. Копия настроек создаётся рядом с `settings.json` в `%LOCALAPPDATA%/SimDeck/`.
4. Подключите Android или Safari, запустите FS25 и войдите в машину. Включите клавиатурный ввод в Companion. Окно FS25 должно быть активным.
5. Проверьте в подходящей машине или орудии: «Опустить / поднять», «Включить агрегат», «Выбрать культуру», «Двигатель», «Сигнал» (удержание), «Магазин». Действия, которых нет у текущего орудия, не должны вызывать видимого эффекта.
6. Отпустите «Сигнал» и проверьте, что звук прекратился. При потере фокуса игры удерживаемая клавиша тоже должна отпускаться.

Кнопки для мыши, осей и отдельной клавиши-модификатора, например одного Shift, SimDeck передать не может. Если нужное действие не импортировалось, переназначьте его в FS25 на обычную клавишу или сочетание и прочитайте файл снова.

## Автоматические проверки

В корне репозитория:

```powershell
dotnet run --project companion/SimDeck.Tests/SimDeck.Tests.csproj -c Release
dotnet build companion/SimDeck.App/SimDeck.App.csproj -c Release
```

Требуется версия SDK из `global.json`. Тесты проверяют синтаксис клавиш, каталог профилей, сохранение пользовательских кнопок и импорт. Они не заменяют проверку действий в самой FS25.
