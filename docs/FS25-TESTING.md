# Проверка Farming Simulator 25

## Профиль кнопок

1. В Companion выберите **Farming Simulator 25**. Если меняли клавиши в игре, нажмите **«Прочитать клавиши FS25»** и выберите `inputBinding.xml` из `Documents/My Games/FarmingSimulator2025`.
2. Проверьте обновлённые назначения в таблице. Импорт не меняет игровой файл; перед изменением профиля создаётся копия настроек Companion.
3. Подключите Android или Safari, откройте FS25, включите ввод в Companion и держите окно игры активным. На подходящем орудии проверьте включение агрегата, выбор культуры, двигатель и удержание сигнала. Недоступные текущей машине действия могут не иметь видимого эффекта.
4. Проверьте одну кнопку **«Прицепить / отцепить»**: Q выполняет доступное действие. Отдельная Ctrl+Q больше не входит в стандартный профиль; при необходимости добавьте её в редакторе Companion.

## Живое состояние орудий (дополнительный мод)

1. Скопируйте `FS25_SimDeckStatus.zip` из релиза в папку `Documents/My Games/FarmingSimulator2025/mods` без распаковки. При запуске конкретного сохранения откройте экран **Модификации/дополнения**, щёлкните карточку **«SimDeck: состояние орудий»** и нажмите **Пробел — выбрать**. Проверьте, что карточка стала зелёной и счётчик выбранных модов вырос, затем войдите в технику. [Описание мода](../mods/FS25_SimDeckStatus/README.md).
2. Выберите плуг или другое опускаемое орудие и нажмите V. На Android/Safari состояние должно смениться с **«Поднято»** на **«Опущено»** и обратно. Для агрегата с включением проверьте B; на комбайне это состояние молотилки. Для машины с двигателем проверьте запуск/остановку.
3. Смените выбранное орудие клавишей G: пульт должен показывать новое выбранное орудие. Выйдите из техники либо отключите мод: статус не должен оставаться «включённым» без свежих данных.

## Данные сохранения и план

1. В игре сохраните ферму. Companion должен найти последний `savegame*` и показать время сохранения; на Android/Safari откройте профиль FS25. Сверьте название, карту, период, деньги и несколько полей с игрой.
2. Измените состояние поля и сохраните ещё раз. Экран должен обновиться после записи, без вымышленных промежуточных значений. Если игра закрыта или сохранение старое, проверьте пометку **«данные устарели»**.
3. При наличии JSON-плана версии 1 нажмите **«Загрузить план FS25»**, выберите файл и проверьте задачи. Неправильный JSON должен дать понятную ошибку, не стирая ранее загруженный план.
4. Сверьте предупреждения советника. Доступность культуры для посева требует файлов установленной FS25; без них это правило не утверждает, что посев разрешён или запрещён.

Чтение сейва и локального файла состояния подтверждено синтетическими тестами. Мод версии 1.0.5 проверен в FS25 1.23.1.0 на тракторе Challenger MT635 с культиватором: двигатель передавался как `motor="true"`, а `lowered` менялся `true → false → true` вслед за действием V и подсказкой игры. Включение молотилки и работа с несколькими одновременно навешенными орудиями ещё требуют проверки в игре. Непрерывных показаний скорости, топлива, склада и цен эти источники пока не дают.

## Автоматические проверки

```powershell
dotnet run --project companion/SimDeck.Tests/SimDeck.Tests.csproj -c Release
dotnet build companion/SimDeck.App/SimDeck.App.csproj -c Release
cd android
./gradlew testTabletDebugUnitTest testPhoneDebugUnitTest assembleTabletDebug assemblePhoneDebug
```

Тесты используют только синтетические сейвы. Игровые XML-файлы GIANTS можно добавить локально для дополнительных интеграционных проверок, но не публиковать.
