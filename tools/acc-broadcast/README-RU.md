# Карта и пилоты ACC — SimDeck 0.9.24

Для приборов и колёс достаточно Shared Memory игры. Для вкладки **«Трасса»** нужен дополнительный штатный канал **Broadcasting ACC**; отдельный игровой мод или выделенный сервер не нужен.

1. Запустите ACC хотя бы один раз, затем полностью закройте игру.
2. Запустите `Install-ACC-Broadcast.cmd` из распакованного архива. При необычном расположении документов используйте `Enable-ACC-Broadcast.ps1 -ConfigDirectory "путь к Config"`.
3. Установщик сохраняет резервную копию `broadcasting.json`, включает порт 9000, если канал был выключен, и сохраняет существующие пароли. Для пустых паролей создаются отдельные случайные значения подключения и команд. Файл записывается в штатном формате ACC (UTF-16 LE без BOM), чтобы игра не сбросила канал при запуске. Другие игровые настройки не меняются.
4. Откройте заезд ACC с соперниками и выберите профиль ACC в Companion.
5. На планшете/Safari откройте **«Трасса»**. В SimDeck Phone она доступна в нижней навигации; пит-стоп остаётся в **«Ещё → Пит-стоп и MFD»**.

Companion читает пароль из локального файла самостоятельно и соединяется только с ACC на этом ПК. Пароль не передаётся телефону и не включается в профиль для обмена. Клиент отправляет только регистрацию и запросы списка участников/трассы; команды камер, HUD и повтора не используются.

## Показания и ограничения

- Имена, номера, команды, общий порядок, категория кубка и времена кругов приходят от игры. Фильтр Pro/Pro-Am/Am/Silver/National — категория кубка, а не класс GT3/GT4.
- Машина **«ВЫ»** определяется по локальному `playerCarID` из Shared Memory, независимо от машины, на которую направлена камера наблюдателя.
- Контур собирается по координатам машин на трассе, упорядоченным по положению на круге. До проезда круга он может быть неполным; большие пропуски не соединяются. Пит-лейн и повторы не добавляются в контур. После перезапуска Companion контур изучается заново.
- Интервалы **≈** — оценка времени между прохождениями одной точки. Это не официальный тайминг сервера. При недостатке истории, в боксах, вне активной гонки или при задержке данных показывается прочерк. В тренировке/квалификации вместо интервала показывается лучший круг.
- Цвет маркера соответствует категории кубка, белый ободок — игроку. Нажмите строку пилота для подробностей; повторное нажатие закрывает её.
- При задержках остаются последние показания с отметкой устаревания. Обычные игровые кнопки доступны независимо от свежести карты при активной игре и разрешённом вводе.
- Broadcasting запрашивается с интервалом 200 мс; приборы продолжают читаться из Shared Memory. Это разные источники и разные частоты.

Если приборы работают, а участники не приходят, проверьте диагностику телеметрии Companion и полностью перезапустите ACC после установщика. Вернуть прежние настройки можно при закрытой игре, восстановив созданную резервную копию `broadcasting.json`.
