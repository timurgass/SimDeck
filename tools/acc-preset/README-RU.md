# Пресет SimDeck для Assetto Corsa Competizione

Пресет добавляет в `keyboardSettings` файла `controls.json` 33 клавиатурные команды, которые совпадают с кнопками профиля ACC в SimDeck. Настройки руля, педалей и геймпада сохраняются.

## Установка

1. Полностью закройте ACC.
2. Запустите `Install-ACC.cmd` двойным щелчком.
3. Откройте ACC, затем выберите профиль **Assetto Corsa Competizione** в Companion.

Перед изменением автоматически создаются резервные копии `controls.before-simdeck-ДАТА-ВРЕМЯ.json` и `saveSettings.before-simdeck-ДАТА-ВРЕМЯ.json`. Второй файл нужен, потому что установщик отключает автоматическое управление двигателем ACC и разрешает ручное выключение зажигания.

## Основные назначения

| Команда | Клавиша |
|---|---|
| Пит-лимитер | `P` |
| Зажигание включить / выключить | `I` / кнопка SimDeck через `F2` и MFD |
| Стартер | `S` |
| Свет / мигание / дождевой фонарь | `L` / `H` / `R` |
| Дворники | `W` |
| TC + / − | `Ctrl+T` / `Alt+T` |
| TC2 + / − | `Ctrl+2` / `Alt+2` |
| ABS + / − | `Ctrl+A` / `Alt+A` |
| Карта двигателя + / − | `Ctrl+M` / `Alt+M` |
| Баланс тормозов + / − | `Ctrl+B` / `Alt+B` |
| MFD | стрелки, `Enter`, `Backspace`, `Insert` |
| Открыть страницу пит-стопа MFD | `F1` |

ACC 1.10.4 не предоставляет отдельную клавиатурную команду `IgnitionOff`. Кнопка **ЗАЖИГАНИЕ ВЫКЛ** в SimDeck использует штатную страницу электроники: `F2` открывает её, после чего Companion делает 12 переходов вниз и устанавливает зажигание в `ВЫКЛ`. Поэтому `F2` должен оставаться назначенным на **Set MFD Electronics**, а автоматическое управление двигателем должно быть выключено — установщик делает это сам.

Чтобы полностью вернуть прежнее состояние, закройте игру и восстановите обе созданные резервные копии.
