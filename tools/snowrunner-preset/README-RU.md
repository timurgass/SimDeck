# SnowRunner: нейтраль N

Полностью закройте SnowRunner, распакуйте файлы и запустите `Install-SnowRunner-Neutral.cmd`. Он назначает **только нейтраль NumPad6**, сохраняет остальные назначения и делает резервную копию рядом с файлом настроек. Если NumPad6 занята другим игровым действием, установщик останавливается без изменения файла. Назначение вращения камеры в отдельном режиме FlyCamera сохраняется, как и у других стандартных клавиш NumPad.

Если найдено несколько профилей или Steam не найден, выполните в PowerShell `./Install-SnowRunner-Neutral.ps1 -SettingsPath "путь к user_settings.cfg"`. Можно также назначить NumPad6 вручную в игровых настройках управления. После запуска игры в Companion нажмите «Прочитать клавиши SnowRunner» для переноса своей раскладки.

Файлы также находятся в папке `snowrunner-preset` Windows Companion. [Профиль](../../SNOWRUNNER-PROFILE.md).
