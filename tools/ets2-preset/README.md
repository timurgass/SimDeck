# Полный пресет ETS2 для SimDeck

Архив `SimDeck-ETS2-Preset-0.8.7.zip` содержит установщик, `preset-actions.json`, это руководство и файл `НАЧАТЬ-ЗДЕСЬ.txt`. Полностью распакуйте архив в отдельную папку; запуск CMD из окна архива не поддерживается.

1. Сохраните игру и **полностью закройте ETS2**.
2. Дважды щёлкните `Install-ETS2-Preset.cmd`. Если найдено несколько профилей, выберите номер нужного профиля. Права администратора не нужны.
3. Запустите ETS2, выберите тот же профиль, откройте **Options → Keys & Buttons** и проверьте нужные команды. В Companion выберите **Euro Truck Simulator 2**, включите **«Разрешить клавиатурный ввод»** и вернитесь в игру.

Установщик назначает все **29 действий** типового профиля SimDeck. В частности, `E` — двигатель, `Space` — ручник, `L` — фары, `K` — дальний, `N` — пневмосигнал, `9` — смена камеры, `1/2` — прямой выбор вида, `F8/F9` — скорость круиза. Полный список — в `preset-actions.json` и [руководстве ETS2](https://github.com/timurgass/SimDeck/blob/v0.8.7/ETS2-PROFILE.md). Клавиши основного вождения, руль, педали, геймпад и другие действия игры не перезаписываются. Если на вашей клавиатуре или в вашей раскладке клавиша занята другой игровой командой, проверьте конфликт в настройках ETS2 после установки.

Перед изменением создаётся резервная копия `controls.sii.simdeck-*.bak` рядом с игровым файлом. При повторном запуске уже установленный пресет не создаёт новую копию. Если формат `controls.sii` неизвестен или отсутствует хотя бы одна из 29 команд, установщик останавливается **до записи**. Для возврата прежних назначений закройте ETS2, сохраните текущий файл отдельно и восстановите нужную резервную копию под именем `controls.sii`.

Дополнительные команды PowerShell:

```powershell
.\Install-ETS2-Preset.ps1 -ListProfiles
.\Install-ETS2-Preset.ps1 -Preview
.\Install-ETS2-Preset.ps1 -ProfileId 'имя_папки_профиля'
.\Install-ETS2-Preset.ps1 -ControlsPath 'полный путь к controls.sii'
```

Для команд `-Preview`, `-ProfileId` и `-ControlsPath` игра также должна быть закрыта, если указан её настоящий профиль. Старый `Install-ETS2-Cruise.cmd` из версии 0.8.6 менял только F8/F9; новый полный установщик заменяет его.

Пневмосигнал требует установленного аксессуара на самом грузовике. Если физическая `N` в игре молчит, пресет не сможет добавить этот звук.
