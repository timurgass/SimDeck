# SimDeck 0.7.0

Android-пульт, локальный веб-пульт для Safari и Windows Companion для BeamNG.drive, F1 24 и F1 25. Это тестовая сборка, не версия 1.0 из плана.

Профили F1 24 и F1 25 используют одну проверенную раскладку: [F1-24-PROFILE.md](F1-24-PROFILE.md) — 69 кнопок, Keyboard Preset 2, разделы и вкладки. Настройка новой игры описана в [F1-25-PROFILE.md](F1-25-PROFILE.md): Companion ожидает процесс `F1_25` и принимает UDP-формат 2025 или совместимый 2024.

## Что реализовано

- WPF Companion: локальный WSS-сервер Android, HTTP-пульт Safari, обнаружение через DNS-SD, pairing, отзыв доступа, редактор действий и выбор профиля игры.
- Kotlin/Compose Android и Safari: приборы, страницы кнопок, состояние колёс и болида, карта трассы с пилотами, запросы инженеру и подготовка пит-стопа.
- F1 24/25: скорость, RPM, передача, топливо, ERS, температуры, давление, износ и повреждения. Парсер учитывает изменённые размеры участников и повреждений UDP 2025.
- Мод BeamNG: реальные скорость, обороты, передача и режим коробки; аркада D/N/R, реализм R/N/1/2/3…; максимальные RPM и количество передач берутся из автомобиля. OutGauge — резервный источник. Данные старше 500 мс скрываются.
- Lights, Horn, Ignition, Reset: нажатия и удержание, отмена жестов, 500-мс аренда ввода и отпускание при потере фокуса/связи.
- Демонстрационный источник, явно помеченный в обоих приложениях; игровой ввод в нём отключён.
- Хранение настроек, защищённый Android Keystore-токен, проверка протокола и интеграционные тесты UDP → WSS.

## Профиль BeamNG

22 действия на четырёх страницах: Основное, Системы, Свет, Возврат. Включены ESC/TCS, привод, блокировки, понижающий ряд, режим коробки, поворотники, аварийка и прочее. Полный список и клавиши: [BEAMNG-PROFILE.md](BEAMNG-PROFILE.md). Старые назначения сохраняются при обновлении, новые добавляются автоматически. Обновите мод до 0.2.1 и перезагрузите машину Ctrl+R для индикации кнопок. Ближний свет обозначается зелёным, дальний синим; включённые переключатели остаются затемнёнными по данным игры.

## Как передать профиль F1 другу

К GitHub Release приложите `SimDeck-F1-Preset-0.7.0.zip`. Друг закрывает игру и запускает из архива `Install-F1-24.cmd` либо `Install-F1-25.cmd`. Установщик находит игру, создаёт резервную копию трёх XML и меняет только Keyboard Preset 2; остальные пресеты сохраняются. Исходники установщика находятся в `tools/f1-preset`.

После этого другу нужны Windows Companion и Android APK либо Safari в той же локальной сети. В игре следует выбрать Keyboard Preset 2 и включить UDP на `127.0.0.1:20777`, 60 Hz, формат соответствующей игры.

## Быстрый запуск

1. Распакуйте всю папку Companion из поставки и запустите `SimDeck.exe`. Не переносите EXE отдельно от остальных файлов.
2. Установите `SimDeck-0.7.0-debug.apk` на Android 10+ либо нажмите в Companion «Подключить iPhone / Safari · тест» и откройте показанный адрес на iPhone в той же сети.
3. ПК и Android должны быть в одной локальной сети. Если Windows предложит сетевой доступ, разрешите его для частной сети. Программа сама не меняет Firewall. Если потребуется ручное правило: TCP 9443 для Companion и mDNS UDP 5353, только локальная подсеть/частный профиль.
4. В Companion нажмите «Подключить планшет». На Android выберите найденный ПК, сравните **все 64 символа** отпечатка, отметьте совпадение и введите код. Код действует 2 минуты.
5. Включите «Демонстрация» на ПК, чтобы проверить приборы без игры. Затем выключите этот режим для BeamNG.
6. Установите `SimDeck-0.2.1-BeamNG.zip` в пользовательскую папку игры `mods`, оставьте включёнными сторонние протоколы и перезагрузите машину (Ctrl+R). Это источник скорости, RPM и режима коробки. Подробности: [мод BeamNG](beamng/README.md). OutGauge на `127.0.0.1:4444` поддерживается как резерв, но не передаёт режим коробки.
7. Свяжите игровые действия с клавишами и задайте **те же клавиши** в Companion. L/H/I/R — стартовые примеры, а не обещанные настройки BeamNG. После сохранения назначений нужно повторить pairing.
8. Включите клавиатурный ввод в Companion и вернитесь в окно игры. Процесс по умолчанию `BeamNG.drive.x64`; при необходимости укажите фактическое имя без `.exe`.

Horn работает, пока палец удерживается. Lights и Reset посылают импульс 100 мс.

**IGNITION: строго сначала короткое нажатие, затем отдельное удержание.** Первое касание должно закончиться быстрее 500 мс: Companion отправит 100-мс импульс настроенной клавиши зажигания. После его успешного завершения подпись кнопки меняется на «Теперь удерживайте: запуск». При следующем касании та же клавиша нажимается сразу и удерживается ровно до отпускания пальца. Лишний короткий импульс при отпускании не отправляется. Удержание первым действием блокируется без какого-либо игрового ввода.

Одна завершённая короткая команда разрешает одно следующее удержание; для следующей попытки снова требуется короткое нажатие. Разрешение также сбрасывается при потере фокуса игры, соединения, отпускании всего ввода и Reset. Это контроль последовательности команд, а не измеренное состояние зажигания автомобиля. Используется прежний бинд зажигания; на текущем ПК это `V`. В BeamNG короткое нажатие и удержание этой клавиши штатно различаются. [Описание системы зажигания BeamNG](https://www.beamng.com/game/news/patch/beamng-drive-v0-27/).

Состояния фар и зажигания подтверждаются расширенной телеметрией мода 0.2.1. Не запускайте Companion с повышенными правами без необходимости; несовпадение уровней привилегий с игрой может блокировать SendInput.

При недоступном mDNS на Android есть резервное подключение. Для локального USB-стенда используйте `adb reverse tcp:9443 tcp:9443`, затем `127.0.0.1:9443` и отпечаток Companion. Такой путь не требует изменения Firewall.

## Сборка из исходников

Windows: .NET SDK **10.0.401**, Java 17, Android SDK platform 35 и build-tools 36.0.0. Gradle Wrapper **8.9** находится в `android/`. Android Studio открывает папку `android/`.

```powershell
dotnet build companion/SimDeck.App/SimDeck.App.csproj -c Release
dotnet run --project companion/SimDeck.Tests/SimDeck.Tests.csproj -c Release
dotnet publish companion/SimDeck.App/SimDeck.App.csproj -c Release -r win-x64 --self-contained true -o artifacts/Companion
cd android
.\gradlew.bat testDebugUnitTest assembleDebug
```

Android SDK указывается через `ANDROID_HOME` или локальный `android/local.properties`; локальные пути не коммитятся. Запуск `SimDeck.exe --demo` включает демонстрацию. `--data-dir <папка>` позволяет изолировать настройки для разработки.

Структура: `companion/SimDeck.Core` — parser и доменная логика, `SimDeck.App` — WPF/Windows/сеть, `SimDeck.Tests` — исполняемый набор проверок; `android/app` — Compose-клиент; `protocol` — контракт и fixtures.

## Ограничения этой поставки

Это ранняя сборка для контролируемого тестирования. Есть готовый профиль BeamNG с четырьмя страницами. Ещё нет редактора, Room-хранилища панелей, полноценных Generic-профилей, автоматического импорта пользовательских биндов, виртуального HID, QR, автоматического обнаружения игры и установщика. Игру выбирает поле процесса, а телеметрия определяется поступлением OutGauge-пакетов.

Работа mDNS через конкретный роутер и команды внутри реальной BeamNG требуют проверки на пользовательском оборудовании. Успешные тесты parser и WSS не заменяют эту проверку.

При штатном отключении, потере Wi-Fi, фокуса или heartbeat удержания отпускаются. При аварийном завершении самого Companion независимого watchdog пока нет — это обязательная задача до внешней alpha. Текущий код не выдаёт такую гарантию. До проверки на реальной игре используйте только некритичные назначения.

Настройки Windows: `%LOCALAPPDATA%/SimDeck/settings.json`; сертификат — личное хранилище сертификатов текущего пользователя. Доверенные устройства удаляются кнопкой «Отозвать доступ». Приложение не записывает PIN и открытые токены в настройки Windows.

## Проверка и следующий этап

Смотрите `VALIDATION.md` для фактических результатов этой сборки. Следующие задачи: реальная сессия BeamNG + планшет, независимый watchdog, сохранённые Generic-профили, затем редактор сетки. Полный план находится рядом с исходниками в документе «SimDeck — план разработки.md».

Версия 0.1.1 установлена на Samsung SM-X115. Пользователь подтвердил работу четырёх действий версии 0.1 в игре. Новая последовательность IGNITION дополнительно проверена на планшете через записывающий тестовый backend без отправки клавиш в игру. Затем исходное подключение восстановлено, Companion обновлён на прежнем месте и запущен в обычном режиме. Настройки N/H/V/R и pairing сохранены. После перезапуска снова включите «Разрешить клавиатурный ввод» в Companion.
