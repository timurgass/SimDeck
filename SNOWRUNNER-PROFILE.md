# SnowRunner — SimDeck 0.9.28

Профиль для `SnowRunner.exe`: 23 действия на страницах **Вождение**, **Коробка**, **Функции**, **Навигация**. Для телефона: **Езда**, **Техника**, **Лебёдка**, **Груз**, **Ещё**; все страницы и свои действия доступны через «Ещё».

## Установка

1. Обновите Companion и Android/Phone APK из [релиза](https://github.com/timurgass/SimDeck/releases/tag/v0.9.28). Для Safari достаточно обновить Companion и перезагрузить страницу.
2. В Companion выберите **SnowRunner** и откройте редактор действий.
3. Нажмите **«Прочитать клавиши SnowRunner»**, выберите `user_settings.cfg`. Обычно Steam хранит его в `userdata/<ваш Steam ID>/1465360/remote/`; другие установки — в `Документы/My Games/SnowRunner/base/storage/<профиль>/`. Диалог предлагает найденный файл.
4. Импорт меняет только профиль SimDeck с резервной копией. Игра и сохранения не изменяются. Передача мыши или неназначенные сочетания не угадываются; такие действия сверяйте вручную в игре.
5. Подключите устройство по USB или Wi-Fi и вернитесь в активное окно SnowRunner. Грузовик можно оставить на ручнике.

## Клавиши

| Действие | Заводское назначение |

| Двигатель | B |
| Ручник | Пробел |
| Полный привод / блокировка | E / Q |
| Фары / сигнал / камера | L / G (удержание) / 1 |

| L− / L / L+ | NumPad 1 / 4 / 7 |
| Автомат / H / R | NumPad 5 / 8 / 2 |
| Функции | V |
| Быстрая лебёдка / тянуть | F / F (удержание) |

| Управление грузом | C |

Блокировка может требовать L; AWD, H, кран и другие операции зависят от установленного оборудования. Кран, упаковка, прицеп, ремонт, заправка и эвакуация выбираются в **меню функций игры**: произвольные прямые клавиши для этих пунктов больше не предлагаются.

## Живые данные

Companion читает текущую машину **пять раз в секунду**: скорость, топливо и ёмкость бака, состояния двигателя, полного привода и блокировки, число колёс, прочность двигателя, коробки, бака и подвески. Значения повреждений переводятся из игровых очков в проценты; исходный остаток прочности также виден.

Модель определяется по однозначному совпадению семейства подвески и числа колёс в `initial.pak` вашей установки. Геометрия осей читается оттуда же. При нескольких совпадениях показывается общее название и известное число колёс. Иллюстрация соответствует классу, а не точной 3D-модели конкретного грузовика. Если живых данных ещё нет, доступна ручная схема 4/6/8/10 колёс.

Читатель проверен для **1.886173.SNOW_DLC_18**, SHA-256 EXE `198B10794B58B511CFFDFD3FC0F6D5927903FCCD1AA08F0E55DCCC95D00A4A2B`. При другом файле EXE чтение отключается до проверки новой раскладки памяти. Проверяются указатели, границы чисел и смена машины. Используется только чтение процесса; нет изменения памяти, внедрения DLL или вызовов игровых функций. Отдельный мод не требуется, игровые XML и изображения не распространяются.

Непроверенные значения (RPM и передача) отображаются неизвестными. Нажатие кнопки не считается подтверждением состояния. Краткая задержка телеметрии сохраняет последние показания с отметкой возраста и не выключает обычные клавиши; отсутствие активного окна игры по-прежнему блокирует ввод.
