# FS25_SimDeckStatus

Версия **1.3.1.0** для SimDeck 0.9.9 сокращает интервал живых состояний до 200 мс. После замены ZIP полностью перезапустите FS25. «Поля» читаются из сохранения отдельно, без контуров участков. [Новый интерфейс и частоты](../../docs/UI-PROFILES-099.md).

Дополнительный мод для Farming Simulator 25. Он раз в 0,2 секунды считывает состояние **выбранного** орудия и машины: опущено/поднято, агрегат или молотилка включены/выключены, двигатель запущен/остановлен. Мод записывает только небольшой локальный `simdeckStatus.xml` в пользовательскую папку FS25. Companion читает этот файл и передаёт подтверждённые состояния на Android и Safari.

Установка: скачайте `FS25_SimDeckStatus.zip` из релиза и скопируйте его, не распаковывая, в папку `Documents/My Games/FarmingSimulator2025/mods`. Перезапустите игру. В меню **Карьера** выберите сохранение и нажмите **Продолжить**. На экране **Модификации/дополнения** найдите карточку **«SimDeck: состояние орудий»** (внизу списка), щёлкните её и нажмите **Пробел — выбрать**. Карточка должна стать зелёной, а счётчик выбранных дополнений увеличиться на один. Затем нажмите **Начать** и войдите в машину. Если папка Documents перенесена в OneDrive, используйте фактическую папку пользовательских данных FS25.

Версия 1.3.0.0 дополнительно передаёт модель, класс и колёса управляемой машины, цепочку подключённых орудий и их доступные состояния. Кнопки по-прежнему показывают состояние выбранного орудия; новая схема перечисляет всю цепочку. При выходе из машины данные очищаются. Обновите также Companion/Android до 0.9.6. [Автоматический выбор техники](../../docs/AUTO-VEHICLE.md).

Мод не управляет техникой и не меняет сохранения. Если конкретная техника не поддерживает метод состояния, SimDeck оставляет его неизвестным. Состояние не угадывается по последнему нажатию. Для проверки см. [FS25-TESTING.md](../../docs/FS25-TESTING.md).

В версии 1.3.0.0 отдельно определяются жатки, плуги, культиваторы и сеялки. Место крепления (спереди/сзади) вычисляется по положению орудия относительно машины. Отсоединённое оборудование отсутствует в цепочке. Новому определению нужен полный перезапуск FS25 после замены ZIP.

Версия 1.3.0.0 читает категории магазина, уточняет общий тип по возможностям машины и различает самоходное/прицепное оборудование. Передаются также удерживаемые ручные инструменты, когда они доступны игровому API. Архив содержит `EquipmentCategories.lua`: не исключайте этот файл при собственной сборке мода. [Библиотека схем](../../docs/FS25-EQUIPMENT-096.md).

## Версия 1.4.0.0 / SimDeck 0.9.10

Состояние техники записывается каждые 200 мс. Новый `MarketPrices.lua` отдельно читает текущие предложения продажи через `storageSystem:getUnloadingStations()` и `getEffectiveFillTypePrice()` и раз в 5 секунд записывает `simdeckPrices.xml`. Цены показываются в отдельной вкладке «Цены», за 1 000 л, с денежной подписью игры. Метод чтения основан на [FS25 API GIANTS](https://gdn.giants-software.com/documentation_scripting_fs25.php?category=78&class=762&version=engine). Станции не фильтруются по `appearsOnStats`: на Riverbend Springs этот флаг отключён у нескольких настоящих покупателей, включая зерновую мельницу и речные терминалы.

Скачайте [FS25_SimDeckStatus.zip](https://github.com/timurgass/SimDeck/releases/download/v0.9.10/FS25_SimDeckStatus.zip), полностью закройте FS25, замените ZIP в папке модов и снова загрузите сохранение с включённым модом. В архиве должны быть `MarketPrices.lua`, `EquipmentCategories.lua`, `SimDeckStatus.lua`, `modDesc.xml` и `icon.dds`. Файлы состояния создаются автоматически в пользовательской папке FS25; отправлять их в GitHub не нужно. Перезапуск только сохранения не заменяет загруженный Lua-код.
