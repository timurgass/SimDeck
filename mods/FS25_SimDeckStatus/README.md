# FS25_SimDeckStatus

Дополнительный мод для Farming Simulator 25. Он раз в 0,4 секунды считывает состояние **выбранного** орудия и машины: опущено/поднято, агрегат или молотилка включены/выключены, двигатель запущен/остановлен. Мод записывает только небольшой локальный `simdeckStatus.xml` в пользовательскую папку FS25. Companion читает этот файл и передаёт подтверждённые состояния на Android и Safari.

Установка: скачайте `FS25_SimDeckStatus.zip` из релиза и скопируйте его, не распаковывая, в папку `Documents/My Games/FarmingSimulator2025/mods`. Перезапустите игру. В меню **Карьера** выберите сохранение и нажмите **Продолжить**. На экране **Модификации/дополнения** найдите карточку **«SimDeck: состояние орудий»** (внизу списка), щёлкните её и нажмите **Пробел — выбрать**. Карточка должна стать зелёной, а счётчик выбранных дополнений увеличиться на один. Затем нажмите **Начать** и войдите в машину. Если папка Documents перенесена в OneDrive, используйте фактическую папку пользовательских данных FS25.

Версия 1.2.0.0 дополнительно передаёт модель, класс и колёса управляемой машины, цепочку подключённых орудий и их доступные состояния. Кнопки по-прежнему показывают состояние выбранного орудия; новая схема перечисляет всю цепочку. При выходе из машины данные очищаются. Обновите также Companion/Android до 0.9.5. [Автоматический выбор техники](../../docs/AUTO-VEHICLE.md).

Мод не управляет техникой и не меняет сохранения. Если конкретная техника не поддерживает метод состояния, SimDeck оставляет его неизвестным. Состояние не угадывается по последнему нажатию. Для проверки см. [FS25-TESTING.md](../../docs/FS25-TESTING.md).

В версии 1.2.0.0 отдельно определяются жатки, плуги, культиваторы и сеялки. Место крепления (спереди/сзади) вычисляется по положению орудия относительно машины. Отсоединённое оборудование отсутствует в цепочке. Новому определению нужен полный перезапуск FS25 после замены ZIP.
