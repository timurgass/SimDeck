# 0.7.2 — совместимый ввод и диагностика третьего ПК

Добавлен переключатель **«Совместимый ввод Virtual-Key»**. По умолчанию сохраняется проверенный режим Scan Code; Virtual-Key предназначен для компьютеров, где Companion получает команду и `SendInput` возвращает успех (`injected`), но игра игнорирует scan code.

Статус управления теперь показывает ожидаемый процесс, фактически активный процесс и текущий режим ввода. Диагностика F1 показывает число полученных и отклонённых UDP-пакетов и отличает отсутствие пакетов от несовместимого формата. Выбранный режим ввода сохраняется между запусками.

Добавлены проверки сохранения совместимого режима и преобразования расширенных клавиш между Scan Code и Virtual-Key. Всего проходит 158 проверок .NET.
