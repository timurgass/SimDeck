# Телеметрия SimDeck для BeamNG

Мод использует штатную систему пользовательских UDP-протоколов BeamNG 0.32+.
Проверяемая установленная версия игры: 0.39.4. Он не заменяет файлы игры и не управляет машиной.

1. Скопируйте `SimDeck-0.2.1-BeamNG.zip` в `mods` внутри пользовательской папки BeamNG. ZIP распаковывать не нужно. Пользовательская папка доступна через launcher → Manage User Folder.
2. Убедитесь, что мод включён в менеджере модов и в настройках протоколов разрешены сторонние протоколы (`protocols_others_enabled`, по умолчанию включены).
3. Перезагрузите машину через Ctrl+R либо загрузите машину заново. Если игра ещё не обнаружила архив, перезапустите игру.
4. Запустите Companion 0.8.2 и Android 0.8.2 либо Safari-пульт. Пакеты идут только на `127.0.0.1:4444`, затем Companion передаёт их подключённому пульту. Для этого мода порт UDP Companion должен быть 4444.

Передаются скорость колёс (м/с), RPM, фактическая передача, режим помощника коробки, максимальная передача и максимальные RPM автомобиля, топливо и педали. В режиме `arcade` положительные передачи отображаются как D, нейтраль как N, отрицательные как R. В `realistic` показывается реальный номер положительной передачи без фиксированного ограничения шестью ступенями. Режим помощника не равнозначен типу установленной коробки.

Режим меняется автоматически по каждому пакету; ручной переключатель в SimDeck не нужен. Отсутствие известных полей режима у нестандартного контроллера не подменяется аркадой: показывается фактическая передача. Режим P отдельно не выводится согласно выбранной схеме R/N/число.

Поток отправляется с частотой до 30 Гц и только для машины первого игрока (ограничение штатной системы протоколов). При отсутствии свежего пакета 500 мс приборы показывают прочерки. Companion объясняет отсутствие пакетов или занятый порт.

OutGauge остаётся резервным источником. Если оба потока включены, свежие расширенные пакеты SimDeck имеют приоритет, чтобы режим коробки не пропадал между обновлениями. В OutGauge режим коробки отсутствует.

Исходник: `mod/lua/vehicle/protocols/simdeckTelemetry.lua`. Для отключения достаточно деактивировать этот мод в игре.

Документация API: https://documentation.beamng.com/modding/protocols/

Мод 0.2.1 также передаёт ближний/дальний свет, состояния аварийки, поворотников (без мигания самой кнопки), противотуманок, полного привода, понижающего ряда, переключаемых блокировок, сцепки, зажигания и спецсигналов. Для недоступных значений посылается признак неизвестного состояния. ESC/TCS с несколькими режимами не сводится к ложному включено/выключено.

Серые кнопки пульта означают, что клавиатурный ввод выключен либо окно BeamNG не активно. Телеметрия при этом может продолжать отображаться. Включите ввод в Companion и вернитесь в игру.
